# GitHub y acceso persistente desde ChatGPT

El repositorio público permite consultar el código. La biblioteca personal se consulta mediante la conexión privada de Mi Academia, ya alojada y registrada en la cuenta propietaria.

Consulta [Conexión alojada de Mi Academia](conexion-alojada.md) para abrir el sitio, usar el plugin desde un chat nuevo y entender sus límites. En ese documento se distingue la instalación comprobada de la disponibilidad y autenticación de las herramientas en cada chat.

La [documentación oficial sobre conexiones MCP](https://developers.openai.com/api/docs/guides/custom-mcp-server) explica el uso de servidores conectados. El servicio no depende de que el ordenador esté encendido, pero no garantiza consultas automáticas en todas las conversaciones.

Los datos de aprendizaje, las respuestas y las copias permanecen fuera del repositorio GitHub. La nube y la aplicación local conservan almacenes e historiales independientes, con importación explícita de sesiones JSON y sin sincronización automática.
